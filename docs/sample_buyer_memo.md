## Scope and Limitations

- Public US buyers only. Private acquirers such as Ripple, Stripe, Kraken and Fidelity can be among the most relevant buyers for a crypto target, and they are not covered because they have no EDGAR filings or market data.
- Figures in the table are filled by code from Yahoo Finance. Figures in the text passed an automated check that they appear in a tool result, which does not prove they were interpreted correctly.
- Sources are built by code from filings actually retrieved, and quotes were checked word for word against them. That shows the words are in the filing, not that the inference drawn from them is right.
- Filing text comes from each buyer's latest 10-K and 10-Q. Events after the date in the Latest filing column are not captured, so check recent news before relying on any buyer's status.
- Code calculates fit scores from yes/no factors the model answers from the filings. Those answers are still model judgment, so use the scores to sort, not as precise ratings.
- GS: Yahoo debt/equity (671.2) does not match the balance sheet recomputation (3.54x).
